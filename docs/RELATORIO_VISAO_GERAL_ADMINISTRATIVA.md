# Visao Geral Administrativa

Central de Controle, apenas para esses perfis ativos e autorizados. Os estoques
operacionais, dados, warehouse_codes e politicas existentes foram preservados.

A especificacao ampliada, arquitetura, seguranca, consultas, testes e limites
estao documentados no [relatorio do Dashboard Global](RELATORIO_DASHBOARD_GLOBAL_ALAMO.md).
